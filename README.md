## 👨‍💻 Quickstart for Collaborators (隊員協作指引)

### 1. Clone & Run Locally
```bash
git clone https://github.com/RK-group-coder/nasa-space.git
cd nasa-space
npm install
npm run dev
```

### 2. Git Branching Workflow (分支規範)
Please do not push directly to `main`. Create your feature branch:
```bash
# 確保取得最新進度
git checkout main
git pull origin main

# 開立個人分支
git checkout -b feature/your-feature-name

# 提交並推送
git add .
git commit -m "feat: description of work"
git push -u origin feature/your-feature-name
```
Then submit a **Pull Request (PR)** on GitHub for review and merge.
